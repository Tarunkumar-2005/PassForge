# PassForge — Secure Password Generator

A cryptographically secure password generator built with React + Vite.

**Built by:** Tarun Kumar VS · varadatarunkumar5@gmail.com  
**Built for:** [Digital Heroes](https://digitalheroesco.com)

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build & Deploy

```bash
npm run build
```

Deploy the `dist/` folder to Vercel — or connect your GitHub repo and Vercel auto-deploys.

## Tech Stack

- React 18 + Vite 5
- window.crypto API (no Math.random)
- Pure CSS, Space Grotesk + Space Mono fonts
- Vercel (free Hobby plan)
